# Website Analysis Workflow Instructions

## Overview
This workflow guides you through a comprehensive website analysis using the 15-section framework. Follow these steps systematically to produce a detailed analysis report.

## Prerequisites
Before starting, ensure you have:
- The website URL to analyze
- Access to the website (or ask user for access if needed)
- Understanding of the business context (gather from user if not provided)

## Step 1: Gather Context (5 minutes)

### 1.1 Collect Business Information
Ask the user or gather:
- **Website URL**: The site to analyze
- **Business description**: What does the business do?
- **Target audience**: Who are their primary customers?
- **Business goals**: What are they trying to achieve with the website?
- **Current challenges**: Any known issues or concerns?
- **Competitors**: Who are their main competitors? (optional but helpful)

### 1.2 Initial Site Visit
- Visit the website in a browser
- Test on both desktop and mobile views (if possible)
- Note your immediate first impressions
- Check multiple key pages (homepage, pricing, about, etc.)

## Step 2: Load Framework and Checklist

### 2.1 Load Analysis Framework
- Load the complete framework from: `{framework}`
- Review all 15 sections to understand what to evaluate
- Note the evaluation criteria, common issues, and best practices for each section

### 2.2 Load Comparison Checklist
- Load the checklist from: `{checklist}`
- Use this as a quick reference during analysis
- Note the scoring system and benchmarks

## Step 3: Execute Comprehensive Analysis (30-45 minutes)

### 3.1 Initial Assessment
Spend 5 minutes on initial assessment:
- Can you understand what they do in 3 seconds?
- Is the value proposition clear?
- What's your first impression of trust/credibility?
- What stands out (positively or negatively)?

### 3.2 Systematic Framework Analysis
Go through each of the 15 sections from the framework:

1. **Value Proposition Analysis**
   - Evaluate clarity, relevance, differentiation, credibility
   - Note specific issues and opportunities

2. **Hero Section Evaluation**
   - Assess headline, subheadline, CTA, visual, mobile experience
   - Check above-the-fold content

3. **CTA Optimization**
   - Review all CTAs throughout the site
   - Evaluate placement, copy, design, relevance

4. **Social Proof & Trust Signals**
   - Check for testimonials, logos, case studies, reviews
   - Assess visibility and credibility

5. **Content Structure**
   - Evaluate information architecture
   - Check heading hierarchy, scannability, flow

6. **Pricing Presentation**
   - Assess pricing visibility and clarity
   - Evaluate plan differentiation and value communication

7. **Conversion Optimization**
   - Identify friction points
   - Evaluate forms, navigation, conversion paths

8. **SEO & Discoverability**
   - Check title tags, meta descriptions, heading structure
   - Evaluate technical SEO basics

9. **UX Analysis**
   - Assess navigation, design consistency, usability
   - Check accessibility and visual hierarchy

10. **Competitive Positioning**
    - Evaluate differentiation messaging
    - Assess positioning clarity and consistency

11. **Mobile Experience**
    - Test responsive design
    - Check touch targets, navigation, performance

12. **Content Quality & Depth**
    - Assess content value, completeness, currency
    - Evaluate writing quality

13. **Trust & Credibility**
    - Check contact info, About page, legal pages
    - Assess professionalism and security indicators

14. **Performance & Technical**
    - Evaluate page speed (use tools if available)
    - Check for broken links, SSL, Core Web Vitals

15. **Analytics & Measurement**
    - Assess tracking setup (if visible or user provides info)
    - Note recommendations for measurement

### 3.3 Competitive Comparison (if applicable)
If competitors were provided:
- Visit competitor sites
- Compare key elements side-by-side
- Identify what competitors do better
- Identify what the analyzed site does better
- Note differentiation opportunities

## Step 4: Prioritize Findings (10 minutes)

### 4.1 Categorize Issues
Organize all findings into:
- **Critical**: Issues blocking conversions (fix immediately)
- **High Priority**: Significant impact on business goals
- **Medium Priority**: Important but not urgent
- **Low Priority**: Nice to have improvements

### 4.2 Identify Quick Wins
List improvements that are:
- Low effort to implement
- High impact on conversions/business
- Can be done quickly

## Step 5: Create Analysis Report (15 minutes)

### 5.1 Load Template
- Load the report template from: `{template}`
- Use this structure for your output

### 5.2 Write Executive Summary
- 2-3 paragraph overview
- Key strengths
- Critical issues
- Top 3 recommendations

### 5.3 Document Detailed Findings
For each of the 15 sections:
- Current state assessment
- Specific issues identified
- Impact on conversion/business
- Recommendations with priority level

### 5.4 Create Prioritized Action Plan
- Organize recommendations by priority
- Include expected impact for each
- Note effort required

### 5.5 List Quick Wins
- Low-effort, high-impact improvements
- Implementation suggestions

### 5.6 Provide Testing Recommendations
- A/B tests to consider
- Elements to test
- Success metrics

### 5.7 Recommend Tools & Resources
- Tools for implementation
- Helpful resources
- Best practice examples

## Step 6: Review and Refine

### 6.1 Quality Check
- Ensure all 15 sections are covered
- Verify recommendations are actionable
- Check that priorities are clear
- Confirm quick wins are identified

### 6.2 Finalize Report
- Save to output file: `{default_output_file}`
- Present to user for review

## Notes

- **Be Objective**: Focus on data and best practices, not personal preferences
- **Be Specific**: Provide concrete examples and recommendations
- **Be Actionable**: Every finding should have a clear recommendation
- **Prioritize**: Not all issues are equal - focus on impact
- **Be Constructive**: Frame issues as opportunities
- **Use Evidence**: Reference best practices and benchmarks
- **Consider Context**: Understand business goals and audience
- **Think Mobile-First**: Always consider mobile experience
- **Focus on Conversion**: Keep business goals in mind

## Output Requirements

The final report should:
- Be comprehensive (all 15 sections covered)
- Be actionable (clear recommendations)
- Be prioritized (critical issues first)
- Include quick wins
- Reference the framework and best practices
- Be professional and constructive in tone
