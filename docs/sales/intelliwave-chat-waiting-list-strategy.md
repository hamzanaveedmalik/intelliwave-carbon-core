**Required Fields:**

**Optional Fields:**
- Store name
- Store URL
- Number of products
- Current support solution (if any)

**Incentives:**
- 50% off first 3 months
- Early access (launch 1 week before public)
- Free setup assistance
- Priority support

### Email Service Provider

**Options:**
- **Mailchimp** - Easy setup, free tier
- **ConvertKit** - Great for creators, good free tier
- **SendGrid** - Reliable, good deliverability
- **Formspree + Email** - Simple, already using Formspree

- Product updates
